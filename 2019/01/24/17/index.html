Mihomo 文件命名说明及使用建议

文件命名格式

命名结构:

各字段含义

  • 系统类型
    名称 说明
    linux Linux系统
    windows Windows系统
    darwin macOS系统
    android Android系统
  • CPU架构
    名称 说明
    amd64 Intel/AMD 64位CPU, 最常见于PC和服务器
    arm64 ARM 64位CPU, 如树莓派, ARM服务器
    armv7 ARM 32位CPU
    386 x86 32位CPU
  • amd64-v1/v2/v3 含义
    v1, v2, v3 表示 AMD64 CPU 指令集优化等级, 不是 Mihomo 版本.
    版本 CPU要求 性能 兼容性 适用场景
    amd64-v1 基础 x86-64 普通 ⭐⭐⭐⭐⭐ 老旧CPU, 不确定CPU型号
    amd64-v2 SSE4 等新指令 略高 ⭐⭐⭐⭐ 大多数2010年后的CPU
    amd64-v3 AVX2 等高级指令 更高 ⭐⭐⭐ 较新的CPU, 支持AVX2
  • go120 含义
    示例: 其中:
    go120 表示该版本使用 Go 1.20 编译.
    它不代表:
    • CPU型号
    • Linux版本
    • Mihomo版本
      go120 主要用于提高旧系统环境的兼容性.

Linux版本选择建议

快速选择表

使用环境 推荐版本
普通Linux服务器 amd64-v2
2010年后CPU通用选择 amd64-v2
老Linux系统 amd64-v2-go120
不确定CPU amd64-v1
新CPU固定环境 amd64-v3
ARM设备 arm64

推荐版本

适用于:

  • 2010年后的Intel/AMD CPU
  • VPS服务器
  • 家庭服务器
  • x86软路由

推荐:

特点:

  • 性能和兼容性平衡
  • 覆盖范围广
  • 推荐作为默认版本

老系统推荐

适用于:

  • CentOS 7
  • 老旧Linux系统
  • 老VPS环境

推荐:

特点:

  • CPU支持范围与v2相同
  • 对旧Linux环境更友好

最大兼容版本

适用于:

  • 不确定CPU型号
  • 需要一份程序部署多台机器

推荐:

特点:

  • 支持更多老CPU
  • 性能略低于v2

新CPU性能版本

适用于:

  • Intel Haswell及更新CPU
  • AMD Ryzen系列

推荐:

特点:

  • 使用更多CPU指令优化
  • 性能略高
  • 老CPU可能无法运行
